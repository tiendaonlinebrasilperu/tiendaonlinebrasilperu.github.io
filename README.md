# Mar y Sol Essence — tienda online gratuita

## Qué contiene
- Catálogo responsive
- Buscador y categorías
- Carrito
- Pedido por WhatsApp
- Datos guardados en el navegador del cliente
- Diseño adaptable a celular y computadora

## Para personalizar
1. Abre `products.js`.
2. Cambia `WHATSAPP_NUMBER` por tu número.
3. Sustituye los productos de ejemplo.
4. Coloca tus fotografías dentro de `assets/`.
5. En cada producto, escribe el nombre del archivo de foto en `image`.
6. Sube toda la carpeta a GitHub Pages.

## Importante
Esta primera versión no tiene base de datos ni panel administrativo. Los pedidos se envían a WhatsApp. Es una opción gratuita y sencilla para comenzar. Después podemos añadir una base de datos gratuita con Google Sheets/App Script para registrar automáticamente pedidos, clientes y stock.
